# ADR-0003: Cloudflare D1 default; Neon Postgres via recipe

## Status

Accepted (2026-05-09)

## What

Cloudflare D1 (SQLite at edge) is the default relational data layer. Drizzle is the ORM ([ADR-0004](0004-drizzle-orm.md)). Migrations live in `drizzle/` as SQL files generated by `drizzle-kit generate`.

## When this default is right

- Small to mid-size data, modest write volume, simple relational queries
- No need for JSONB, Postgres-only features, or full-text search beyond FTS5
- Want zero ops on the data layer

## When to switch

- Need JSONB, advisory locks, `LISTEN`/`NOTIFY`, or other Postgres-specific features
- Hit D1's per-database size or write-throughput limits
- Need cross-region multi-master replication
- **Recipe:** [`data-layer/switch-to-neon-postgres.md`](https://github.com/mwheatfill/app-platform-recipes/tree/main/recipes/data-layer) (Neon + Cloudflare Hyperdrive; mechanical 10–30 min swap because the ORM API is identical)

## Notable

- SQLite write concurrency is per-database; high-write workloads need Postgres.
- D1 replicates to all Cloudflare locations; reads are millisecond-latency from anywhere.
